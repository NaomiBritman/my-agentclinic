# Fitness and Nutrition Tracker

A website that helps a person keep up with exercise and nutrition, day by day.

## Input from stakeholders

- The user wants a daily list of exercises to do and a nutrition tracker.
- Each day, the user marks whether they completed everything on that day's list.
- The difficulty of the exercises goes up from week to week.
- The plan is personal: it is based on the user's weight and individual details.
- Progress must be gradual and stay within safe limits; the site must not encourage extreme dieting or overtraining, and it is not medical advice.
